# HR Consult – Pratima Vaidya

A professional, responsive single-page HR consultant website for **Pratima Vaidya**.

## 📁 Files

| File | Description |
|------|-------------|
| `index.html` | Main HTML page (all content) |
| `style.css` | All styles — responsive, Navy/White/Gold theme |

## 🚀 How to View Locally

### Option 1 – Open directly in a browser
1. Clone or download the repository.
2. Double-click `index.html` **or** drag it into any modern browser (Chrome, Firefox, Edge, Safari).

### Option 2 – Local development server (recommended to load Google Fonts)
```bash
# Python 3
python -m http.server 8080

# Node.js (npx)
npx serve .
```
Then open `http://localhost:8080` in your browser.

## 🌐 Deploy to GitHub Pages

1. Push the repository to GitHub.
2. Go to **Settings → Pages**.
3. Set the source to the `main` branch, root (`/`) folder.
4. GitHub will publish the site at `https://<username>.github.io/<repo-name>/`.

## ✨ Features

- Sticky header with logo and smooth-scroll navigation
- Hero section with professional placeholder avatar
- Specializations grid (9 items)
- Industries Served grid (8 items)
- Certifications / Expertise badges
- Footer with Contact and About Me sections
- Navy blue, white, and gold color scheme
- Google Fonts (Playfair Display + Inter)
- Fully responsive (mobile-first)
